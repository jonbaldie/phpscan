# Triage labels

| Role | GitHub label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | A maintainer must evaluate the request. |
| `needs-info` | `needs-info` | The reporter must supply missing information. |
| `ready-for-agent` | `ready-for-agent` | Scope and verification support unattended work. |
| `ready-for-human` | `ready-for-human` | Implementation needs a human. |
| `wontfix` | `wontfix` | The request will not be implemented. |

Use `bug` and `enhancement` for issue classification. Use one readiness role
at a time. The ready-queue and closure rules are in
[issue tracker](issue-tracker.md).
