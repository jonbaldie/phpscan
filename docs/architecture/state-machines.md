# Scanner state machines

This map records the behavior-preserving conversion from the inventory at
commit `7321412e99effaf33d16fe320e350f13881d4224`. Named variants live beside
the code that owns their transitions. There is no shared interpreter or
second continuation engine.

Recursive allowances remain branch-local. EOF precedence differs between
readers and is preserved. These limits describe bounded static analysis,
not a claim that every PHP program is analyzed completely.

## CLI and execution

| Machine | Representation and transitions | Reset and terminal behavior |
|---|---|---|
| Argument fold | `Format` admits text, GitHub, or SARIF. `Opts` holds independent `Maybe<Format>` and `Maybe<String>` outcomes. `opt`, `opts`, and `go` parse and dispatch. | Each invocation starts with text output and no error. The right fold preserves leftmost-option precedence. An unknown option takes precedence over an invalid format or missing path. Help/version are special only as the sole argument. |
| Project analysis | `RootAnalysis` is `RootComplete{reports}` or `ProfilesPending{root,sources,reports}`. `project.analyze` selects the next phase and `project.complete` performs optional boundary discovery and enrichment. | Each root discovers and reads sorted sources independently. | File scheduling | Existing `scan_all` splits independent source lists with a shrinking allowance, then uses `scan_seq`. | This is bounded scheduling over immutable data, not a hidden lifecycle. Report order is retained and sorted before rendering. |
| Reporting | Existing `status` maps finding and incomplete counts to exit 0, 1, or 2. | Incomplete analysis takes precedence over findings. Formatting, sorting, serialization, and version comparison are ordinary calculations. |

## Verification

`make lint` executes the lexical, tree, JSON, analysis, budget, and profile
transition suites as well as the existing suites. `make test` drives the native
CLI and installer and tests the CVE runner's failure transitions with controlled
transport and scanner commands. `make cves` fetches pinned upstream source,
verifies checksums, and scans it without executing downloaded PHP.

To compare real artifacts, run:

```sh
python3 scripts/compare-state-machines.py /path/to/baseline /path/to/candidate
```

The comparison requires identical exit status, stdout, and stderr on the same
generated source and project paths. Its corpus covers strings, delimiters,
suppression, taint propagation, summaries, CLI precedence, strict Composer JSON,
and framework profile acceptance, rejection, and collisions. Transition tests
also exercise selected direct fuel boundaries. These checks establish the
recorded examples, not equivalence over every possible input.

`LAWS.bend` and `PROOF.bend` retain the suppression invariant. That proof does
not establish scanner completeness or whole-refactor equivalence.
